编程模板 5 条

读报错、补注释、生成函数、重构样式、补测试。

读懂报错

用途：把错误翻译成人话

下面是浏览器控制台的报错和我对应的代码片段。请先说明这条报错在说什么，再指出最可能出问题的位置，最后给出两种修法并说明各自副作用。不要重写整段代码。

补注释

用途：让代码能被讲解

给下面这段 JavaScript 逐块补中文注释，说明这一块在做什么、为什么要这么做。注释面向初学者，不解释语法常识，只解释意图与关键判断。

生成函数

用途：按需求给出最小实现

写一个 JavaScript 函数：接收一个数组和一个关键词，返回数组里文本包含关键词的元素。要求：不引入任何库，函数体不超过 12 行，包含空数组与关键词为空两种情况的处理，并在末尾给出两个调用示例。

重构样式

用途：把重复 CSS 收拢

下面是我写的 CSS，有很多重复的颜色和圆角。请用 CSS 变量重构，保持视觉结果完全一致，只改变写法。输出重构后的完整代码，并列出新增的变量名及用途。

补测试用例

用途：交作业前自测

为下面这个表单校验函数写测试用例清单：覆盖正常输入、边界长度、非法字符、空值四类情况。每条用例写清输入、期望结果和判定理由，用清单形式输出，不需要测试框架代码。
