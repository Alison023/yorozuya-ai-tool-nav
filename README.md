# YOROZUYA 万事屋 · 工具导航与学习资源站

《Web 前端开发技术》综合实验作品（2025 级软件工程）。共 28 个页面，全部使用 HTML5 + DIV/CSS 布局 + 原生 JavaScript，无第三方框架、无表格布局。

## 怎么打开

直接用浏览器打开根目录的 `index.html` 即可（`file://` 本地运行，不需要服务器）。
如需模拟真实环境，也可在本目录执行 `python -m http.server 8080`，再访问 `http://localhost:8080`。

## 实现要点

- **双级导航**：一级栏目 hover 弹出二级子菜单，移动端由按钮展开为纵向列表。
- **首页轮播**：三屏自动播放（5 秒），圆点可点、左右箭头可切换，鼠标移入暂停。
- **表单校验**：账号 4–16 位字母数字下划线、密码 6–20 位含字母与数字、两次密码一致、协议勾选、账号查重，全部在前端完成。
- **登录与收藏**：账号、登录态、收藏均存于 `localStorage`，不提交服务器；换设备或清缓存后失效。
- **收藏**：详情页与卡片上的「收藏」按钮，未登录时提示跳转登录；收藏夹页面可取消收藏。
- **其他**：滚动吸顶与阴影、回到顶部、卡片滚动显现、搜索按文字过滤当前页工具卡片、响应式三档宽度。

## 配色（dir-3「抽屉工装」）

工装灰白 `#E8E6E1`（底）、面板 `#F4F2EE`、墨 `#1A1A1A`（主）、工业橙 `#C6491B`（强调，取货牌油墨感）、分割线 `#BFBCB4`。视觉语言：直角、2px 描边、硬阴影（位移阴影）、等宽字做标签；动画尊重系统「减弱动态效果」设置。
