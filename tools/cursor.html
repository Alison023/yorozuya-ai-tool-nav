Cursor

把代码编辑器与对话能力合在一起，能直接读你项目里的文件，改代码时不用来回复制。

它适合干什么

  • 读整个前端项目，解释某段 CSS 为什么没生效
  • 按现有文件风格补一个页面
  • 批量改类名、抽公共样式

四步上手

  1. 打开项目文件夹，让它先读出目录结构
  2. 说明要改哪个文件、改成什么效果，避免“随便优化”
  3. 让它给出改动清单，再逐条确认
  4. 改完在浏览器里自己跑一遍，别只看它说完成

用的时候注意

让它改动前先备份，或使用版本管理，避免一次改坏多个文件。
